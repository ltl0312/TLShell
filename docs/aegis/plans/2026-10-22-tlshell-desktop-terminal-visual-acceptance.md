## 1. 设计契约缺口（开工前必须补，8 项）

计划书 §6.1 只定义了 3 个颜色（background / foreground / cursor）与 4 个尺寸（size / line_height / padding / border_radius）。
作为视觉验收对象，以下 8 项缺失会直接导致验收不可判定：

| # | 缺口 | 后果 | 建议取值 | 归属 |
|---|---|---|---|---|
| G1 | **无 CJK 回退字体** | `Cascadia Mono` 不含汉字。R5 要求"中文不乱码"，实际会渲染成豆腐块 □ | `[font] fallback = ["Sarasa Mono SC", "Microsoft YaHei UI", "Noto Sans Mono CJK SC"]`；CJK 字宽固定 2 格 | M1（阻塞 R5） |
| G2 | **ANSI 16 色未定义** | `Get-ChildItem` / `vim` / `git --color` 的颜色由 alacritty_terminal 默认值决定，不受 `[colors]` 控制，可能出现 1.8:1 的不可读色 | 显式写全 16 色，且 black / bright-black 需替换（见 §3.1 V-05） | M1 |
| G3 | **无焦点/失焦区分** | Win+D 后终端可见但打不了字，界面上没有任何提示；用户会以为程序卡死 | 失焦：光标转空心 + 外框 alpha 降至 0.55；获得焦点：实心块 | M2 |
| G4 | **无选区颜色** | 选中文本的对比度无法判定，可能白底白字 | 见 §3.7 V-37（含一组不可同时满足的证明） | M5 |
| G5 | **无 shell 未就绪 / 已退出状态** | 冷启动可能出现白屏闪；shell 崩溃后画面冻结、无任何提示 | 冷启动先铺背景色；退出时保留末屏 + 一行状态 | M1 |
| G6 | **无配置错误呈现** | `config.toml` 写错时静默回落默认值，用户改了半天不知道为什么没生效 | 首屏顶部 1–2 行显示 `<路径>:<行>:<列> <原因>`，其余照常给终端 | M3 |
| G7 | **无 WorkerW 挂载失败的用户可见提示** | 计划书只要求"日志告警"。降级为普通窗口后，用户无法解释为什么 Win+D 就看不见了 | 首屏一行 `desktop layer unavailable (WorkerW not found) — running as normal window` | M2 |
| G8 | **opacity 无可用性下限** | 计划书 M4 验收②要求"0.5 明显更透"，但 0.5 下默认深色配色的合成对比度只有 2.71:1（见 §2.3），文字不可读 | 配置钳制到 `[0.55, 1.0]`，并在 README 标注 0.70 为可读性下限 | M4 |

> 另外一项实现选择建议：`SetLayeredWindowAttributes` 是**整窗统一 alpha**，文字与背景一起被稀释，
> 且字形抗锯齿边缘会被二次混合（发糊）。若 M4 改用 `UpdateLayeredWindow` 逐像素 alpha，
> 可做到「背景 0.88 + 文字 1.0」，文字边缘保持锐利，选区也能局部不透明。
> 代价是每帧一次 900×420×4 ≈ 1.5 MB 的 DIB 拷贝（CPU 下约 0.3 ms，可接受）。建议 M4 直接走逐像素。

## 2. 量化基线（默认配置算出来的硬数字）

### 2.1 配色与对比度（WCAG 2.2，sRGB 相对亮度）

默认值：bg `#1e1e2e`、fg `#cdd6f4`、cursor `#f5e0dc`。

| 组合 | 实测比 | 阈值 | 判定 |
|---|---|---|---|
| fg / bg（不透明） | **11.34 : 1** | ≥ 7（AAA 正文） | ✅ |
| cursor / bg | **12.95 : 1** | ≥ 3（非文本对比 1.4.11） | ✅ |
| ANSI red `#f38ba8` | 7.08 | ≥ 4.5 | ✅ |
| ANSI green `#a6e3a1` | 11.03 | ≥ 4.5 | ✅ |
| ANSI yellow `#f9e2af` | 12.91 | ≥ 4.5 | ✅ |
| ANSI blue `#89b4fa` | 7.79 | ≥ 4.5 | ✅ |
| ANSI magenta `#f5c2e7` | 10.74 | ≥ 4.5 | ✅ |
| ANSI cyan `#94e2d5` | 11.01 | ≥ 4.5 | ✅ |
| ANSI white `#bac2de` | 9.26 | ≥ 4.5 | ✅ |
| ANSI bright-white `#a6adc8` | 7.37 | ≥ 4.5 | ✅ |
| **ANSI black `#45475a`** | **1.80** | ≥ 4.5 | ❌ |
| **ANSI bright-black `#585b70`** | **2.46** | ≥ 4.5 | ❌ |
| 替换建议 black → `#8087a2` | 4.61 | ≥ 4.5 | ✅ |
| 替换建议 bright-black → `#9399b2` | 5.81 | ≥ 4.5 | ✅ |

### 2.2 网格几何（Cascadia Mono，upem 2048 / advance 1200 → 0.5859 em）

窗口 900×420、padding 10、size 14.0、line_height 1.25：

| 量 | 100% (96 DPI) | 125% | 150% (state.json 记的 144) | 200% |
|---|---|---|---|---|
| 单元格宽 | 8 px | 10 | 12 | 16 |
| 行高 | 18 px | 22 | 26 | 35 |
| 内边距 | 10 px | 12 | 15 | 20 |
| 列数 | **110** | **110** | **110** | **110** |
| 行数 | 22 | 22 | 23 | 22 |
| 竖向余量 | 4 px | 16 | 2 | 30 |

- **列数 110 是跨 DPI 不变量**，可当作强断言。
- 行数 22→23 的漂移由行高取整造成，允许 ±1 行；超过 1 行即判缺陷。
- 竖向余量（4 / 16 / 2 / 30 px）必须**集中处理**（统一贴底或上下均分），不允许逐行抖动。

### 2.3 透明度对可读性的实际影响（整窗 alpha 模型）

`fg #cdd6f4` / `bg #1e1e2e` 在纯白壁纸 `#ffffff` 上合成后：

| opacity | 合成 bg | fg/bg | cursor/bg | 判定 |
|---|---|---|---|---|
| 0.50 | `#8e8e96` | **2.71** | 2.90 | ❌ 不可读 |
| 0.60 | `#787882` | 3.51 | 3.79 | ❌ |
| **0.70** | `#62626d` | **4.66** | 5.10 | ⚠️ 刚好过 AA |
| 0.75 | `#565662` | 5.51 | 6.08 | ✅ |
| **0.88（默认）** | `#393947` | **8.23** | 9.24 | ✅ |
| 1.00 | `#1e1e2e` | 11.34 | 12.95 | ✅ |

纯黑壁纸下同样曲线更宽松（0.50 → 3.59，0.70 → 6.15），**所以白色壁纸是判定的最差条件，全部对比度测量都在白壁纸上做**。

### 3.7 选择 / 滚动

| ID | 项 | 判定标准 | 测量方法 | 阈值 |
|---|---|---|---|---|
| V-37 **P0** | 选区可读 | 选中一段文本截图 | 取色 | fg-on-sel ≥ 4.5 **且** sel-vs-effbg ≥ 2.0 |
| V-38 **P1** | 选区在默认 opacity 下复测 | 同上 + `opacity=0.88` + L1 | 同上 | 同上（会失败，见下方结论） |
| V-39 **P2** | 滚动位置指示 | 滚轮回看后 | 目视 | 有"不在底部"的可察觉线索（滚动条或角标），不静默 |

> **V-37/V-38 的定量结论（必须作为设计决策记录）**：在整窗 alpha 0.88 + 白壁纸下，
> 设 eff-bg 亮度 L_b=0.0425、eff-fg 亮度 L_f=0.711，则两条要求分别推出
> `L_sel ≤ 0.119` 与 `L_sel ≥ 0.135`——**空集，无解**。即：任何选区填充色都不可能同时满足。
> 可行路径二选一：
> ① 选区改为「2 px 下划线 + 首尾 1 px 端点标记」，不依赖填充；
> ② 改逐像素 alpha（见 §1 末尾），选区局部不透明，两条要求即可同时满足
>   （opacity ≥ 0.94 时窗口区间为 `[0.101, 0.115]`，取 `#585b70` → 4.71 / 2.08 均通过）。

## 5. 判级与放行门槛

| 级别 | 含义 | 处理 |
|---|---|---|
| **P0** | 阻断：文字不可读、豆腐块、半字裁切、白闪、无焦点提示、撕裂 | 必须修完才进下一里程碑 |
| **P1** | 里程碑内修：ANSI 暗色、选区可读、圆角 AA、IME 候选窗偏移 | 允许带缺陷进下一里程碑，但必须在 M5 前清零 |
| **P2** | 打磨：滚动指示、静置一致性、bold 实现 | 可延后到 1.0 之后 |

**放行判定**：
1. 全部 P0 通过，且每项有截图路径作为证据；
2. §2.2 的跨 DPI 列数 = 110 断言成立；
3. §2.1 中 ❌ 的两个 ANSI 色已替换并复测通过；
4. G1–G8 八项缺口全部落地（有代码或配置为证）。

**不允许**：用"看起来还行"替代取色；用单张截图代表多环境；用 `pwsh` 一张截图代表双版本。

## 6. 反模式：不能作为证据的截图

1. **用好看的壁纸掩盖对比度** —— 所有对比度判定强制在 L1 纯白上做。
2. **用 `opacity=0.5` 的截图证明"玻璃效果好"** —— 那张只能作为 V-04 的反面证据。
3. **只截 100% DPI** —— 计划书 state.json 里 dpi=144 是默认假设，D150 必须截。
4. **只截 `pwsh`** —— R5 明确要求两个版本，`powershell.exe` 的乱码概率更高。
5. **只截终端窗口局部** —— 无法证明 R1/R2，M2 起必须全屏。
6. **截静止画面判断撕裂** —— V-40/V-41 只能录屏。
7. **用光标恰好亮着的帧判断闪烁** —— 连拍必须标注每帧光标状态。

## 7. 可执行方法

### 7.1 截图

- 全屏：`Win + Shift + S` → 全屏，或 `Print Screen`（需在无其他窗口遮挡时）。
- 窗口局部：先 `Alt + Print Screen` 不适用（无标题栏），改用系统截图工具框选，并记录框选坐标。
- 连拍（冷启动、闪烁）：`ffmpeg -f gdigrab -framerate 60 -i desktop cold-start.mp4 -t 2`
- 录屏（撕裂、光标形状）：`ffmpeg -f gdigrab -framerate 60 -i desktop -t 10 out.mp4`
- 放大测量：截图后在图像工具中放大到 400%，按格位像素读数；不要依赖目测"差不多"。

### 7.2 对比度（PowerShell 7，可直接粘贴）

```powershell
function Get-Lum([string]$hex) {
    $h = $hex.TrimStart('#'); $c = @()
    foreach ($i in 0..2) {
        $v = [Convert]::ToInt32($h.Substring($i*2,2),16) / 255.0
        $c += if ($v -le 0.04045) { $v / 12.92 } else { [Math]::Pow(($v+0.055)/1.055, 2.4) }
    }
    return 0.2126*$c[0] + 0.7152*$c[1] + 0.0722*$c[2]
}
function Get-WcagContrast([string]$fg,[string]$bg) {
    $a = Get-Lum $fg; $b = Get-Lum $bg
    $hi = [Math]::Max($a,$b); $lo = [Math]::Min($a,$b)
    return [Math]::Round(($hi+0.05)/($lo+0.05), 2)
}
function Get-Composited([string]$fg,[string]$bg,[double]$alpha) {
    $f = $fg.TrimStart('#'); $b = $bg.TrimStart('#')
    $o = foreach ($i in 0..2) {
        [Math]::Round($alpha*[Convert]::ToInt32($f.Substring($i*2,2),16) +
                      (1-$alpha)*[Convert]::ToInt32($b.Substring($i*2,2),16))
    }
    return ('#{0:x2}{1:x2}{2:x2}' -f $o[0],$o[1],$o[2])
}

Get-WcagContrast '#cdd6f4' '#1e1e2e'                       # 11.34
Get-WcagContrast '#45475a' '#1e1e2e'                       # 1.80  ← 需替换
$bg = Get-Composited '#1e1e2e' '#ffffff' 0.88              # #393947
Get-WcagContrast (Get-Composited '#cdd6f4' '#ffffff' 0.88) $bg   # 8.23
```

### 7.3 网格断言（写进 `cargo test`，比截图更早发现漂移）

```rust
// 纯逻辑，无需窗口：布局计算必须给出与 DPI 无关的列数
#[test]
fn columns_invariant_across_dpi() {
    for scale in [1.0, 1.25, 1.5, 2.0] {
        let m = Metrics::new(14.0, 1.25, 10.0, 900.0, 420.0, scale);
        assert_eq!(m.cols, 110, "cols drift at scale {scale}");
        assert!(m.cell_w == (14.0f32 * 0.585938 * scale).round());
        assert!(m.row_h  == (14.0f32 * 1.25    * scale).round());
    }
}
```
