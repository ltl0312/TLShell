# 视觉验收证据 · M5（v1 收尾）

## 命名与条件

文件名为 `<条目序号>-<短名>-<DPI>-<壁纸>.png`，与
[视觉验收计划](../../plans/2026-10-22-tlshell-desktop-terminal-visual-acceptance.md) 的 `V-xx` 编号对应。

- **DPI**：本机为 130（`GetDpiForWindow` 实测），不是 96。逻辑尺寸换算按 130/96 缩放。
- **壁纸**：`desk` = 当前动态壁纸（Wallpaper Engine，深色照片）。`L1 纯白` 这一最差条件
  **尚未采集**，涉及它的条目一律标「未验」。
- **裁剪**：窗口物理矩形 900×420 @ (40,40)，截图按此裁剪；全屏图另行保留在 `target/`。

## 本目录未覆盖的已知差距（不掩饰）

1. **V-19 圆角抗锯齿不满足**：`SetWindowRgn` 是硬边裁剪，做不出 alpha 过渡。
2. **V-30 没有退出码提示**：shell 退出直接关窗，计划书要求留一行状态。
3. **V-32 错误没有显示到界面**：配置解析错误只进日志，界面上只有底部提示条（未接）。
4. **对比度类（V-01/02/03/06/38）全部未测**：需要白壁纸与像素取样脚本，本轮未做。
5. **录屏类（V-26/40/41）与连拍类（V-24/25/28/29）未做**：本机无录屏工具链。
